## 概要
Class Widgets 2 は、次世代のデジタル時間割ツールです。前世代よりも新しいアーキテクチャと、より洗練されたデザイン言語で、一から作り直されたんやで。

[Class Widgets 1](https://github.com/Class-Widgets/Class-Widgets) と比べると、デザイン、操作性、機能面、全体の完成度が一段上がってるって感じやす。

### 注目ポイント
> このソフトウェアは、まだ正式版をリリースしていません。

### 開発者向けドキュメント

Class Widgets 2 のプラグイン開発に興味ある開発者は、ぜひ参加してや！
